# UK-Maternity-Analysis
A data science project exploring maternity outcomes in England using NHS Maternity Statistics 2024-25.
Exploring Deprivation and Maternity Outcomes in England
Project overview
This data science project explores relationships between socioeconomic deprivation and selected maternity outcomes in England using NHS Maternity Statistics for 2024-25.

Initial research question
How does the level of deprivation relate to maternity characteristics and outcomes recorded in NHS hospitals in England during 2024-25?

Areas of investigation
The analysis will initially explore relationships between deprivation and:

maternal age
method of delivery
antenatal and postnatal length of stay
recorded delivery complications
recorded birth complications
miscarriages and ectopic pregnancies resulting in an NHS hospital stay
Data source
NHS England, NHS Maternity Statistics, 2024-25: Hospital Episode Statistics.

Project status
Repository created. Data understanding and project scoping are in progress.
